# Testing

Run `npm test` on Node.js 22.19+ or 24.11+. The six unit tests exercise valid MIPS ELF metadata, malformed/truncated ELF input, out-of-bounds load segments, non-MIPS targets, invalid ISO input, and an ISO with SYSTEM.CNF and a boot ELF.

`npm run verify:upstream` requires the pinned real PS2Recomp source and tools via `REA_PS2RECOMP_SOURCE`, `REA_PS2_ANALYZER`, and `REA_PS2_RECOMP`, plus locked CMake dependency checkouts. It generates a clearly synthetic ELF containing `addiu v0,zero,42; jr ra; nop`, runs the actual tools through the CLI, checks emitted C++ and function registration, builds a native runner linked with the actual PS2Recomp runtime, and confirms cold/warm artifact identities. This verifies tool invocation, translation output, native compilation, and linking only.

`tooling/build-ps2sdk-smoke.sh` builds `fixtures/sources/ps2sdk-smoke.S` with the pinned ps2dev v2.0.0 EE toolchain and PS2SDK linker script. The linked MIPS ELF was imported and analyzed by Ghidra 12.1.4 with Ghidra Emotion Engine Reloaded v2.1.38 under the `r5900:LE:32:default` language. PS2Recomp translated this ELF, built the native runner, and the runner repeatedly entered and returned from its generated guest function. This confirms function registration and dispatch for this case; it does not independently inspect the resulting register state or prove instruction equivalence. The PS2SDK upstream `hello` sample was also attempted but is incompatible with GCC 15.2.0 because it passes the removed `-mno-crt0` option.

PCSX2 2.8.2 is installed and its process starts. The native PS2SDK runner smoke was bounded at 3 seconds; it wrote `status: timed_out`, exit code 11, and retained the executable identity and elapsed time. Its generated function entered and exited repeatedly, and the runner was terminated cleanly. This only demonstrates native dispatch and timeout cleanup, not correctness. No BIOS is present in the configured BIOS directory, so no reference game can be booted and the PINE listener/reference lane has not been exercised. [PCSX2 requires a BIOS dump from an owned console](https://pcsx2.net/docs/setup/bios/); BIOS files are not distributed by this project.

The pinned upstream PS2Recomp runtime and runner were built with MSVC 19.42. The upstream all-tests executable did not build: MSVC reported internal compiler error C1001 at `ps2_runtime_kernel_tests.cpp:139`. The upstream standalone test suite therefore remains unpassed. CI gates our unit suite, real analyzer/translator/native linking, the PS2SDK fixture build, and a real Ghidra headless import. There are no coverage thresholds, mutation, fuzz, PCSX2 reference, independent native instruction, or gameplay qualification lanes yet.
