# Reproducibility

The current CLI has no npm dependencies and requires Node.js 22.19 or later. `DEPENDENCY_LOCK.json` records upstream revisions, locked PS2Recomp build dependencies, and SHA-256 identities for qualification tool archives. CI downloads and verifies the PS2DEV v2.0.0 Linux package, Ghidra 12.1.4, and its v2.1.38 EE extension before exercising them. The local verification used Windows 11 x64, Node v24.18.0, MSVC 19.42.34433, and CMake 4.0.1; Ghidra ran on Eclipse Temurin 21.0.12+1, and the PS2SDK toolchain ran in Ubuntu 24.04 under WSL2. PCSX2 2.8.2 was installed from its pinned Windows release archive. The CMake runtime build disabled the debug UI and FFmpeg. A full clean-install qualification and PCSX2 BIOS-backed run remain outstanding. Input identity is SHA-256 over the supplied input file bytes.
